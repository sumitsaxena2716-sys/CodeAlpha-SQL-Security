SQL Injection Prevention

This page documents the vulnerable pattern and the secure pattern used by the project.

Unsafe pattern

query = "SELECT * FROM users WHERE username = '" + username + "'"

Concatenating untrusted input into SQL can change the intended query structure.

Secure pattern

cursor.execute(
    "SELECT id, username, password_hash FROM users WHERE username = %s",
    (username,)
)

The database driver treats the supplied value as data rather than SQL syntax.

Data leak prevention

  • Passwords are hashed.
  • Generic authentication errors are shown to users.
  • Database exceptions are logged server-side.
  • .env is excluded from Git.
