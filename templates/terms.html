Terms of Use

CipherShield is an educational project for demonstrating web application security concepts, including parameterized SQL and protection of selected data fields. It is provided as-is for learning and controlled testing.

Permitted use

Use the application only on systems and databases you own or are authorized to test. The Security Lab is designed to submit harmless test values to a parameterized query; do not adapt it to attack third-party systems.

No security guarantee

The project is not represented as independently audited or production-ready. Operators must review code, dependencies, configuration, access controls, backups, monitoring, and applicable legal requirements before deployment.

Account and data responsibility

Use dummy data in demonstrations. Keep credentials and encryption keys confidential. Operators are responsible for handling stored data and providing appropriate user notices.

Changes

These terms should be reviewed by the project owner before a public launch and updated to reflect the actual deployment, jurisdiction, and service practices.
