POLICY

Privacy Policy

Last updated: 24 October 2026

CipherShield is an educational application security project. This policy describes the data handled by the application as currently implemented. A deployment owner should review and update it before public launch.

Information the application stores

  • Account username and email address.
  • Password hash. The application is designed not to store plaintext passwords.
  • Optional phone number and private note, encrypted by the application with AES-256-GCM before database storage when a valid encryption key is configured.
  • Security event records such as event type, username, status, and timestamp.
  • Server-side security logs may include request IP addresses and operational error details.

Cookies and sessions

The application uses a session cookie to maintain authentication and CSRF protection. Cookie security settings depend on the environment; HTTPS and secure cookies must be enabled for production.

Analytics and third parties

No analytics integration or advertising tracker is configured in the supplied project. The interface uses local system font stacks and does not currently load third-party analytics or advertising resources.

Retention and deletion

Account and security-event data remain in the configured database until the database owner deletes them. Log retention depends on the host configuration. The current project does not provide a self-service account deletion workflow.

Security and contact

Use test data for demonstrations. Do not publish real personal information in a public demo. No verified privacy contact address was supplied with this project, so this page does not invent one. The project owner should add a monitored contact method before public launch.
