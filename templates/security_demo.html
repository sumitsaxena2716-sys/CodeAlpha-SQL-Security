This page demonstrates the secure pattern used by the application. The test input is treated strictly as data and is never executed as SQL.

DEFENSEPARAMETERIZED SQL
UNSAFE PATTERNVULNERABLE
query = "SELECT * FROM users "
       + "WHERE username = '" + input + "'"

Raw input changes the SQL statement itself. This can create an injection path.

SECURE PATTERNPROTECTED
cursor.execute(
  "SELECT ... WHERE username = %s",
  (input,)
)

The database receives the SQL structure and the user value separately.
